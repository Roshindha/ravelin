Bundled fonts (B18d). All SIL OFL 1.1; the OFL text of each is next to it. None of the three OFL files declares a Reserved Font Name,
so the subsets keep the original family names; the files are modified versions (Latin subset, axes limited), not the original release files.

Source: https://github.com/google/fonts/tree/main/ofl (the Google Fonts release of each upstream project), fetched 2026-11-18.
